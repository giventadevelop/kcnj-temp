5.2 Create payload requirements

  • All POST bodies must include tenantId (frontend uses withTenantId / proxy injection)
  • Include createdAt and updatedAt ISO timestamps if your validators require them (frontend sends them)
  • Do not require id on POST (or accept null)
  • PATCH payloads must accept id in body (frontend sends id with merge-patch)

5.3 Authentication and tenancy

  • Service JWT (Authorization: Bearer) from Next.js proxy and server actions
  • X-Tenant-ID header required for tenant-scoped reads (see TenantContextFilter)
  • Public pages call /api/proxy/* without Clerk; backend still uses service JWT from proxy
