# Profile Audience CRM v2 — Task Master PRD

## Overview
Add profile-scoped audience capture, CSV import, and bulk email for PERSONAL_PROFILE tenants. Single table profile_audience_contact per tenant. Admin UI in mosc-temp and event-site-manager. Public capture in mosc-temp only.

## Dependencies
