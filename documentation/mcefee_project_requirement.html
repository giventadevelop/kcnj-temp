4. Homepage (Modernist) requirements

Route / uses the Modernist homepage composition: 1b poster hero + on-sale band + optional legacy hero slider + 1a body (timetable, featured event, What we do, about, team, sponsors, CTA).

🏠 Homepage structure
  1. Poster hero (1b) — grayscale Kerala imagery, mission headline, primary CTAs.
  2. On-sale band — ticketed / featured sale messaging when data available.
  3. Legacy hero slider — existing HeroSection under admin Homepage Hero rules (mid-page).
  4. Upcoming events timetable — next dates from event APIs.
  5. Featured event split — large banner with object-contain (no crop).
  6. What we do — interactive 2×2 service cards.
  7. About — foundation mission and contact.
  8. Team — executive committee members (#team-section).
  9. Sponsors — when configured.
  10. Closing CTA — tickets / donate.
✅ Key files: src/components/modernist/ModernistHomePage.tsx, src/styles/modernist-homepage.css, src/app/HomePageClient.tsx

5. Header requirements

📌 Sticky transparent header
  • Sticky / fixed at top of viewport for the homepage.
  • At page top: fully transparent over the dark poster hero; light nav text.
  • On scroll: translucent frosted glass (dark tint + blur) so logo and nav stay readable; no border.
  • No black Admin strip — auth cluster background must stay transparent (no purple/black opaque block).
  • Nav contrast adapts: light labels over dark frost; Admin / avatar / search remain readable.
💡 Implementation: Styles live under body.modernist-home in modernist-homepage.css; the shared Header component keeps position: fixed.

6. Executive team section

👥 Team section (#team-section)
  • Section heading: “The people who run the year” (do not show the eyebrow text “Executive committee”).
  • Do not repeat “Executive committee” on each card.
  • Photos: reduced size (approx. 180px wide), cards centered in a constrained grid.
  • Section content centered (heading, intro, grid).
  • Name on one line (white-space: nowrap).
  • Designation on the next line (prefer designation, fallback title).
  • Data source: /api/proxy/executive-committee-team-members?isActive.equals=true&sort=priorityOrder,asc
⚠️ Data quality: If cards show honorifics like “Mr.” under the name, update Designation in Admin → Executive Committee so the public line shows the real role.

7. Footer requirements

🦶 Footer (homepage light theme)
  • On Modernist homepage: light background (aligned with #f3f2f2 / --mh-bg), dark readable text — not charcoal navy.
  • Copyright (centered), replace legacy charity wording with:
© 2026 KCNJ Malayali Cultural Exchange Foundation for Education and Events
  • Remove footer links: Privacy Policy, Terms of Service, Accessibility (copyright row only).
  • Shared component: src/components/Footer.tsx; light theme overrides scoped via body.modernist-home.

8. Legacy hero slider on homepage

🖼️ Mid-page HeroSection

The existing HeroSection remains available after the on-sale band and still respects tenant Homepage Hero admin settings (default slides, event media, rotation).

Hidden on Modernist homepage only:

  • .hero-left-cta-card — Unite India / Our Mission / Donate Now strip
  • .hero-browse-container — “Browse all upcoming events” control
💡 Why hide: Those controls duplicate Modernist CTAs and clutter the mid-page slider. Hiding is CSS-scoped under .mh-legacy-hero-slider so other themes using HeroSection are unchanged.

10. Acceptance checklist

✅ Verify before release
  • Homepage loads Modernist layout; other routes unchanged.
  • Header sticky; transparent at top; frosted on scroll; no black Admin block; no header border.
  • Nav readable over dark and light sections while scrolling.
  • #team-section: no “Executive committee” eyebrow/card label; names single-line; designation separate; photos smaller; section centered.
  • Hero slider: Mission/Donate strip and Browse-events control hidden on /.
  • Footer: light on homepage; copyright centered as © 2026 KCNJ + foundation name lines; no Privacy/Terms/Accessibility links in that row.
  • Facebook URL documented and reachable: KCNJ FB page.
