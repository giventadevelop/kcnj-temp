Verify that every image shown in the homepage hero slider is eligible under the real product rules, and that images failing any rule do not appear. Do not trust admin UI labels alone — cross-check against API data and the browser console log [HeroSection] Image rotation initialized:.

Environment
  • Frontend: http://localhost:3000/
  • Backend: http://localhost:8080
  • Tenant: NEXT_PUBLIC_TENANT_ID (e.g. mosc_malankara_orthodox_2)
  • Before major scenarios: clear sessionStorage keys containing homepage_hero_section_cache and homepage_tenant_settings_cache, then hard refresh

Pass conditions (image SHOULD appear)

Event media (Admin → Media)

All of the following must be true:

  1. displayEventHeroImages === true in tenant settings (default true)
  2. isHeroImage === true OR isHomePageHeroImage === true
  3. startDisplayingFromDate empty/null OR ≤ today (local date)
  4. eventId is set (standalone media excluded)
  5. Linked event is upcoming/ongoing for the same tenant (endDate ≥ today, or startDate ≥ today; recurring uses next occurrence)
  6. Usable non-expired preSignedUrl or stable fileUrl
  7. Within displayOrder sort and first 24 slides (HERO_SLIDER_CAP)
Tenant default slides (Homepage Hero tab)
  1. defaultHeroIncludeWithEvents === true (default true)
  2. URL protocol is https://
  3. Slide active: true in JSON (homepage does not use admin “random 3 when none active”)
  4. Within defaultHeroMaxDisplayCount (1–6)
  5. Mode applied: slideshow | random | single
Merge order: eligible event heroes first, then active tenant defaults. Fallback /images/hero_section/hero_images/fallback/default-hero.webp (BUNDLED_EMERGENCY_HERO_IMAGE) only when both sources are empty. Homepage heroes must use this constant — do not pass a tenant-specific noImagesFallbackUrl.

- Backend API: http://localhost:8080
- Tenant: NEXT_PUBLIC_TENANT_ID from .env.local
- Clear sessionStorage keys containing homepage_hero_section_cache and homepage_tenant_settings_cache; hard refresh before major scenarios

2) isHeroImage OR isHomePageHeroImage
3) startDisplayingFromDate empty/null OR <= today

Playwright skeleton

How to run

Install browser once, then run the skeleton (requires Playwright browsers):

npm run test:install-playwright
npx playwright test tests/e2e/hero-slider-conditions.spec.ts --config=tests/e2e/playwright.config.ts
The scaffold audits live homepage slides against eligibility helpers and fails if an unexpected URL appears. Expand fixture matrices for F1–F12 / E1–E10 / T1–T7 as data setup becomes automatable.
