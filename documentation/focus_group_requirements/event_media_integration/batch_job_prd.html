Status: Draft

Requirement

Align the batch job database schema and any code that reads event_media or event_focus_groups with the new event_media.event_focus_group_id column. No changes are required to event_details or event_focus_groups table structures.

Schema Sync

  • After the backend has applied its migration, ensure the batch job DB schema (e.g. database/Latest_Schema_Post__Blob_Claude_12.sql or equivalent) is updated to include event_focus_group_id on event_media.
  • If the batch project keeps a copy of the canonical schema file, apply the same change as in the canonical file: add column event_focus_group_id bigint NULL, FK to event_focus_groups(id) ON DELETE SET NULL, and the partial index idx_event_media_event_focus_group_id.

Jobs

If any job reads event_media or event_focus_groups (e.g. reporting, sync, or exports), note that media rows may now have a non-null event_focus_group_id. Add filtering or export of this field only if required by product. No change to job logic is required for backward compatibility; the new column is nullable.

Backward compatibility: The new column is nullable. Existing jobs that do not reference event_focus_group_id continue to run without change.
